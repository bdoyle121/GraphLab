# GraphLab

I made this code a couple months back when I was in Algorithms class at Fordham Univeristy. This assignment has us build out an unfinished graph class. 

This class can do four things it can search a graph using BFS, DFS, Topological Sort and Dijkstra's algorithm which as I say in the comments of the code all four are very useful algrithms in the real work helping to develope things like gps, and other apps like google maps and apple maps.
